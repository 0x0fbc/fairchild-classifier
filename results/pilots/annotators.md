# Annotator comparison

**Preliminary annotator-selection comparison.** Pilot annotations are in `data/pilots/annotators/` (repository-root-relative); final main-study and cross-generator annotations are separately retained in `data/main_corpus/annotations/`. This 300-answer pilot is not the main study's 300-answer cross-generator evaluation. See the [repository guide](../../README.md) for the current manuscript and reproduction workflow.

Generated by `src/sampleAnnotators.py`. Every run annotated the same 30 batches (300 answers): 24 randomly chosen `claude-opus-5-5` raw batches and 6 `claude-sonnet-5` sample batches. Agreement is measured against the reference run `claude-opus-5-5` (`claude-opus-5-5`, reasoning effort medium); its repeat `claude-opus-5-5-repeat` shows how well the reference agrees with itself, with macro F1 0.944. Macro F1 averages per-label F1, with the reference as truth, over the 26 labels the reference marks present in at least 5 answers; relative F1 divides it by the repeat's. Pair agreement covers all 28 labels. Intended present and forbidden absent compare a run with the prompt design. Agreement and design shares cover the batches a run shares with the reference.

Success: ok attempts as a share of logged attempts. Median s: median seconds per attempt. $/request: the cost of all logged attempts, failures included, divided by saved batches. Projected full run: $/request x 3600 requests.

A run qualifies with at least 28 batches, a success rate of at least 0.9, a median of at most 180 s, relative F1 of at least 0.95, both design shares no more than 0.02 below the reference's on the same batches, and a lower cost per request than the reference. The cheapest qualifying run is selected, higher macro F1 breaking ties; if none qualifies, the reference is. A candidate run whose median exceeds 180 s after at least 8 attempts gets no further requests, so its batches stay incomplete.
